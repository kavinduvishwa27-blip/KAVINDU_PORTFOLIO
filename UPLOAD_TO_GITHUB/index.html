// Project 01 · EMMARK Light Fittings Wholesale · 2026

EMMARK Lighting
Website & ERP

A premium public catalogue for a lighting wholesaler, and the secure business platform behind it that runs sales, stock and shipments.

Visit live site ↗ ERP staff sign-in ↗
Client
EMMARK
Role
Full-Stack Developer
Year
2026
Scope
Website · ERP
// 01 — Overview

What it does.

EMMARK imports light fittings from China and sells them wholesale across Sri Lanka. The owner works from China while the sales team works locally, so the business needed one platform both sides could run from — not just a brochure site.

The public website is a fast, mobile-first catalogue of 100 products across six ranges, with a 3D hero, product detail pages, a quote list customers build as they browse, and a “Light Lab” that estimates how much light a room needs and previews colour temperature.

Behind it sits the ERP: leads, quotations, sales orders, invoices, payments, inventory across warehouses, purchase orders, shipments and customs with landed cost, expenses, profitability reports and user roles. Every action in the ERP is monitored: who created, edited, approved or deleted what, and when, is written to an audit log the owner can review from anywhere. The public site never exposes prices, staff logins or customer data.

// 02 — Stack

Built with.

HTML CSS JavaScript Three.js Cloudflare Workers Cloudflare D1 (SQL) Python build tooling Role-based access
// 03 — Highlights

Key features.

01

Live Product Catalogue

Six lighting ranges, filterable product pages and SKU detail views, generated from a single catalogue source.

02

Quote Builder

Customers add fittings to a quote list and send a request; it lands in the ERP as a lead for the sales team.

03

Light Lab Tools

A room lighting calculator (lumens, lux, wattage) and a 2700K–6500K colour-temperature preview.

04

Business ERP

Quotations, invoices, inventory, purchase orders, shipments and customs, behind a staff-only sign-in with role permissions and an audit log of every action.

// 01 — Overview

What it does.

Freelancer College teaches sellable skills such as UI/UX design and Linux in Sinhala, then the system to turn them into paid work. The site needed to explain the programs clearly, show proof, and take people from interest to enrolment.

The public website covers the courses (Designer X and Linux Master), the LEAP method, success stories, webinars, free resources, a blog and checkout, built mobile-first and fast on Cloudflare Pages.

The admin panel manages batch dates and prices, curriculum, FAQs, testimonials and blog posts, and changes go live in about ten seconds with no rebuild. // Project 05 · Self-Initiated · 2026

AI Trading
Signal Platform

A technical analysis web app for crypto and forex markets, powered by an AI agent that reads the news and runs eight strategies in parallel.

Project Type
Self-Initiated
Role
Solo Developer
Year
2026
Strategies
8 in parallel
// 01 — Overview

What it does.

Markets move on news as much as charts. So instead of writing another indicator overlay, I built a platform where an AI agent ingests live news and feeds it into the same engine running technical analysis on crypto pairs and forex.

The engine evaluates eight distinct strategies in parallel for every signal — momentum, mean-reversion, breakout, volume-confirmed trends, and others — and only emits a trade when the strategies agree across both the chart and the news context.

I tracked every emitted signal across more than twenty rounds of live progress checks, watching how each strategy held up under different market conditions and tightening the agent's behavior cycle after cycle.

// 02 — Stack

Built with.

Python AI Agent News API JavaScript Charting Technical Analysis
// 03 — Highlights

Key features.

01

AI News Agent

An autonomous agent pulls financial news in real time and tags each story by market, asset and sentiment before handing it to the engine.

02

Eight-Strategy Ensemble

Trend-following, mean-reversion, breakout and momentum strategies run in parallel — signals fire only when multiple strategies align.

03

Live Tracking & Iteration

Each signal is monitored against actual price action across 20+ live rounds, so strategy weights adapt instead of being hard-coded.

04

Crypto & Forex Coverage

The same engine works on both crypto pairs and traditional forex, so the platform stays useful across asset classes.
